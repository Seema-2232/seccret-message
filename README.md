# Secure Message Encryptor

A Python-based secure message encryption system using AES encryption.

Features:
- AES-based symmetric encryption
- Tkinter Desktop GUI
- Streamlit Web App
- Secure key generation

Tech Stack:
- Python
- Cryptography (Fernet)
- Tkinter
- Streamlit

How to Run:

Tkinter:
python tkinter_app.py

Streamlit:
streamlit run streamlit_app.py
